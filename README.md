## 🎯 Overview

**Toyhisob** helps families keep clear, accurate records for weddings and similar celebrations: who contributed what, what was spent, and what remains to be settled. It replaces paper notebooks and scattered chats with one organized, searchable record.

## 🚀 Getting Started

### Prerequisites

- Node.js 18+ (or Python 3.10+)
- Git

### Installation

```bash
# Clone the repository
git clone https://github.com/ErkinovAsliddin/Toyhisob.git
cd Toyhisob

# Install dependencies
npm install            # or: pip install -r requirements.txt

# Configure
cp .env.example .env

# Run
npm run dev            # or: python app.py
```

Open **http://localhost:3000** in your browser.

> ⚠️ Never commit your `.env` file or any secrets.
